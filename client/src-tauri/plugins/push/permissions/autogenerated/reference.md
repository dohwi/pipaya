## Default Permission

Native push registration and tap metadata for the trusted host

#### This default permission set includes the following:

- `allow-register`
- `allow-pending-tap`
- `allow-set-system-bars`
- `allow-device-name`
- `allow-download-apk`
- `allow-update-progress`
- `allow-install-apk`
