# harness 소개

`pipaya`는 **LLM 코딩 에이전트를 내 서버에서 돌리는** 셀프호스팅 하네스입니다. 두 부분으로 이루어져 있습니다.

| 구성 | 위치 | 하는 일 |
|---|---|---|
| **서버** | `server/` | Bun + Fastify + SQLite로 만든 API 전용 서버. 세션, 도구 실행, 승인 정책, 모델 연결을 관리합니다. |
| **클라이언트** | `client/` | Svelte 5 + Tauri 2로 만든 데스크톱·모바일·웹 채팅 앱. 서버를 조작하는 창입니다. |

명령은 REST로 보내고, 진행 상황은 SSE와 WebSocket으로 받습니다.

## 핵심 원칙

- **모델은 직접 연결합니다.** 내장 제공자가 없습니다. OpenAI Chat Completions, OpenAI Responses, Anthropic Messages와 호환되는 엔드포인트를 직접 등록합니다. API 키는 서버의 SQLite에만 저장되고 서버 밖으로 나가지 않습니다.
- **서버가 정책을 가집니다.** 도구 승인, 작업 디렉터리 제한, 스킬 켜기/끄기는 서버에서 적용됩니다. 어떤 클라이언트로 접속해도 같은 규칙이 적용됩니다.
- **클라이언트는 창일 뿐입니다.** 서버가 일을 하고 상태를 갖습니다. 클라이언트를 닫아도 실행은 계속되고, 다시 접속하면 이어서 볼 수 있습니다.
- **확장은 데이터만 보냅니다.** 클라이언트 확장 코드는 격리된 Worker에서 돌고, 화면에는 검증된 데이터만 전달합니다. ([확장 개요](ext-overview.md))

## 한눈에 보는 기능

- 세션 여러 개를 나란히 띄우는 **세션 그룹** (분할 화면)
- 세션마다 **도구 승인 정책** `auto` / `ask` / `readonly`
- 읽기 전용 **서브에이전트**에게 조사 위임 (`delegate` 도구)
- 컨텍스트가 차면 **압축(compaction)**
- 전역·프로젝트 **스킬**과 `AGENTS.md` 지침
- 데스크톱·웹·Android 알림, 폰 푸시 (선택)
- 기기별 토큰으로 **QR 페어링**
- Docker 샌드박스 실행
