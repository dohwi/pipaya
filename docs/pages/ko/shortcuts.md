앱의 모든 단축키와 변경 규칙입니다. `Mod`는 Windows·Linux에서 {{Ctrl}}, macOS에서 {{Cmd}}입니다. 설정 → 단축키에서 **전부 바꾸거나 없앨 수 있습니다.**

## 기본 단축키

### 일반

| 동작 | 기본 | 설명 |
|---|---|---|
| 사이드바 접기 / 펼치기 | {{Mod+B}} | 좁은 화면에서는 사이드바 서랍을 열고 닫음 |
| 새 대화 | {{Alt+N}} | 빈 화면으로 이동. 그룹 안이면 선택한 창만 새 대화로 바뀜 |
| 현재 대화 닫기 | {{Alt+W}} | 기록은 남고 `대화 열기`로 다시 열 수 있음. 그룹 안이면 다음 창으로 포커스 |
| 작업이 끝난 대화로 이동 | {{Alt+U}} | 끝났지만 아직 안 본 대화(실패 포함)로 이동. 여러 번 누르면 다음 대화로 |
| 대화 열기 | {{Alt+O}} | 닫은 대화를 포함해 목록에서 골라 열기 |
| 설정 열기 | {{Mod+Comma}} | |
| 전체 화면 전환 | {{F11}} | 창을 전체 화면으로 바꾸거나 되돌림 |

### 대화

| 동작 | 기본 | 설명 |
|---|---|---|
| 작업 중지 | {{Escape}} | **고정 키** — 바꿀 수 없음 |
| 대기열 / 끼워 넣기 취소 | {{Alt+Q}} | |

### 모델 · 추론

| 동작 | 기본 | 설명 |
|---|---|---|
| 모델 선택창 열기 | {{Alt+M}} | 모델과 추론 강도를 고르는 창 |
| 즐겨찾기 모델 순환 | {{Alt+Shift+M}} | 별표한 모델만 순서대로 |
| 추론 단계 변경 | {{Alt+T}} | `minimal → … → max`, 끝에서 처음으로 |

### 화면 분할 · 터미널

| 동작 | 기본 | 설명 |
|---|---|---|
| 오른쪽으로 분할 (좌우) | {{Mod+\}} | |
| 아래로 분할 (상하) | {{Mod+Shift+\}} | |
| 새 터미널 | {{Mod+Shift+`}} | 서버의 셸을 지금 작업 폴더에서 엶 |
| 아래에 터미널 열기 | {{Mod+Alt+`}} | 선택한 창 아래에 터미널을 열고 그룹으로 묶음 |

## 기본 지정이 없는 단축키

아래는 **기본값이 비어 있습니다.** 쓰려면 설정 → 단축키에서 직접 지정하세요.

| 구분 | 동작 |
|---|---|
| 대화 이동 | 이전 대화로 이동 / 다음 대화로 이동 / 직전에 보던 대화로 돌아가기 / 대화 검색 |
| 대화 | 대화 분기 / 응답 다시 시도 / 컨텍스트 압축 / 마지막 답변 복사 |
| 스크롤 | 대화 맨 위로 / 대화 맨 아래로 (맨 아래는 자동 따라가기를 다시 켬) |
| 승인 | 승인 방식 변경 (프로젝트 밖만 확인 ↔ 자동) / 도구 실행 승인 / 도구 실행 거부 |
| 분할 | 왼쪽으로 분할 / 위로 분할 |
| 창 이동 | 왼쪽·오른쪽·위쪽·아래쪽 창으로 포커스 / 다음 창으로 포커스 |
| 그룹 | 현재 창을 그룹에서 빼기 |
| 도구 | 작업 폴더 변경 / 스킬 열기 / 다음 서버로 전환 |
| 기타 | 알림음 켜기·끄기 / 라이트·다크 전환 |

> [!WARNING]
> **승인 방식 변경**은 `ask`와 `auto`를 오갑니다. 자동은 묻지 않고 실행하니 단축키를 지정할 때 실수로 눌리지 않도록 주의하세요. 이 값은 서버에 저장되어 새 대화도 따릅니다.

## 키 조합 형식

조합은 `Mod+B`, `Alt+Shift+M`, `Mod+B+V`처럼 문자열로 저장됩니다.

- 수정 키는 **`Mod`, `Alt`, `Shift`** 순서로 쓰고, 그 뒤에 일반 키를 **최대 3개**까지 누른 순서대로 이어 씁니다.
- 키는 `KeyboardEvent.code` 기준이라 **키보드 배열과 무관**하고, macOS에서 {{Alt}}가 글자를 바꿔도 영향이 없습니다.
- 표시는 플랫폼에 맞게 바뀝니다: macOS는 ⌘ ⌥ ⇧, 그 밖은 Ctrl Alt Shift.

## 바꾸는 방법

설정 → 단축키에서 항목을 눌러 **녹음**합니다.

1. 항목을 눌러 녹음을 시작합니다.
2. 원하는 조합을 누릅니다. 누른 키가 화면에 쌓입니다.
3. **체크 버튼**을 눌러야 저장됩니다.

| 키 | 녹음 중 동작 |
|---|---|
| {{Backspace}} | 마지막 키를 취소. 취소할 키가 없으면 **단축키를 지움** |
| {{Escape}} | 녹음 취소 (저장 안 됨) |

- 이미 다른 동작이 쓰는 조합이면 **그 동작에서 가져옵니다.** ("○○에서 이 단축키를 가져왔습니다")
- 일반 키는 3개를 넘을 수 없습니다.
- 기본값에서 바꾼 것만 저장됩니다(`pipaya.keys`). 기본값으로 되돌리면 저장에서 빠집니다.
- 검색창에서 이름·설명·키로 거를 수 있습니다.
- 백업에는 바꾼 단축키만 담깁니다 → [[settings]].

## 동작하지 않는 경우

- 입력창·폼에 글을 쓰는 중이거나 한글 등을 **조합하는 중**에는 단축키가 가로채지 않습니다.
- 대화 상자·팝업 안에서는 해당 창의 키 동작이 우선합니다.
- 브라우저가 이미 쓰는 조합(`Ctrl+W`, `Ctrl+T` 등)은 웹 앱에서 쓸 수 없습니다. 그래서 기본값이 {{Alt}} 조합으로 되어 있습니다.
- 확장이 `shortcuts` 권한으로 추가하는 키는 {{Mod}} 또는 {{Alt}}가 들어가야 하고 **앱의 기본 단축키를 바꿀 수 없습니다** → [[client-extensions]].
