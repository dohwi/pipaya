메시지 입력창의 모든 동작을 정리합니다. 입력창은 글자 외에 `/` 명령, `#` 파일·이미지, `@` 세션 지목, 첨부 파일을 한 줄에서 처리합니다.

## 한눈에 보기

| 입력 | 의미 | 예시 |
|---|---|---|
| `/이름` | 명령, 하위 에이전트, 스킬, 템플릿 | `/compact`, `/skill:review` |
| `#경로` | 작업 폴더의 파일·폴더 지목 | `#src/app.ts 를 고쳐줘` |
| `#image1` | 첨부한 이미지를 순서로 지목 | `#image1 과 #image2 비교해줘` |
| `@이름` | 다른 세션(에이전트) 지목 | `@미나 와 얘기해서 진행해` |
| 붙여넣기·끌어놓기·클립 버튼 | 이미지·파일 첨부 | 스크린샷 {{Mod+V}} |

각 기호는 **단어 맨 앞**(줄 시작 또는 공백 뒤)에 쓸 때만 메뉴가 열립니다. `a#b`, `메일@주소`처럼 단어 중간의 기호는 일반 글자입니다.

## 보내기와 줄바꿈

| 상황 | 키 | 동작 |
|---|---|---|
| 데스크톱, 대기 중 | {{Enter}} | 전송 |
| 데스크톱 | {{Shift+Enter}} | 줄바꿈 |
| 데스크톱, 작업 중 | {{Enter}} | **끼워 넣기** — 진행 중인 작업에 지시 추가 |
| 데스크톱, 작업 중 | {{Alt+Enter}} / {{Ctrl+Enter}} / {{Cmd+Enter}} | **대기열** — 현재 작업이 끝난 뒤 실행 |
| 폰·태블릿(터치) | {{Enter}} | 줄바꿈. 전송은 버튼으로 |
| 한글 조합 중 | {{Enter}} | 조합만 확정하고 전송하지 않음 |

- 오프라인에서는 전송되지 않습니다. 로컬에서 처리되는 `/` 명령은 실행됩니다.
- 컨텍스트 압축 중에는 일반 메시지를 보낼 수 없고 `/` 명령만 가능합니다.
- 작업 중에 보내는 메시지에도 이미지·파일을 실을 수 있습니다.
- 대기열 메시지는 입력창 위 목록에서 개별 취소합니다(`/cancel`, {{Alt+Q}}).

## 추천 메뉴

`/`, `#`, `@`를 입력하면 입력창 위에 메뉴가 열립니다.

![`/`를 입력한 모습. ① 입력창 ② 위로 열린 추천 메뉴에 명령과 스킬이 묶음별로 나옵니다](/assets/img/ui/slash.png)

| 키 | 동작 |
|---|---|
| {{↑}} {{↓}} | 항목 이동 (끝에서 처음으로 순환) |
| {{Enter}} | 선택 (터치 기기는 항목을 탭) |
| {{Tab}} | 선택하되 **실행하지 않고 입력만 완성** |
| {{Escape}} | 메뉴 닫기. 더 입력하면 다시 열림 |

## 이전 입력 불러오기

입력창에서 {{↑}} / {{↓}}로 이 대화에서 이미 보낸 메시지를 거슬러 올라갑니다.

- 커서가 첫 줄({{↑}}) 또는 마지막 줄({{↓}})에 있고 선택한 글자가 없을 때만 동작합니다.
- 불러온 글을 고치면 탐색이 가장 최근 메시지부터 다시 시작합니다.
- 탐색을 시작하기 전에 쓰던 글은 {{↓}}로 끝까지 내려오면 복원됩니다.
- 같은 메시지가 연속되면 한 번만 나옵니다.

입력창이 비어 있으면 가장 최근 메시지가 흐린 글씨로 표시됩니다(작업 중에는 은은하게 빛남).

## 작성 중인 글 보존

대화를 바꿨다가 돌아와도 **글, 첨부 이미지, 첨부 파일**이 대화별로 남습니다. 새 대화 화면도 하나의 보관함입니다.

> [!NOTE]
> 보관은 앱 메모리에만 있습니다. 앱을 새로고침하거나 종료하면 사라집니다.

## # 파일·폴더 지목

작업 디렉터리의 파일을 `#`로 골라 메시지에 경로를 적어 넣습니다.

![`#app`을 입력하면 ② 이름이 맞는 파일이 목록으로 나옵니다](/assets/img/ui/hash.png)

```text
#src/lib/store.svelte.ts 의 연결 로직을 설명해줘
```

### 동작 방식

- 선택하면 `#경로` 글자가 입력창에 들어가고, 선택한 경로는 민트색으로 강조됩니다. 직접 타이핑만 한 경로는 강조되지 않습니다.
- **파일 내용이 자동으로 첨부되지는 않습니다.** 경로 글자가 그대로 전달되고, 에이전트가 필요할 때 `read`로 엽니다. 서버에는 `#` 전용 처리가 없습니다.
- 파일을 고르면 뒤에 공백이 붙고, **폴더를 고르면 메뉴가 열린 채로** 이어서 하위 항목을 고를 수 있습니다.
- 기준 폴더는 **그 세션의 작업 디렉터리**입니다(새 대화는 서버 기본 디렉터리).

### 검색 규칙

입력할 때마다(80ms 지연) 서버에 **이름만** 조회하며 파일 내용은 읽지 않습니다. 정렬 순서:

1. 경로가 정확히 일치
2. 경로가 입력으로 시작
3. 파일 이름이 입력으로 시작
4. 파일 이름에 입력 포함
5. 경로에 입력 포함
6. 글자 순서만 맞는 약식 일치 (`cmps` → `Composer.svelte`)

입력이 비어 있으면 얕은 경로가 먼저, 폴더가 파일보다 먼저 나옵니다. 기본 50개(최대 100개)까지 보여 줍니다.

### 검색에서 제외되는 것

- 폴더: `node_modules` `.git` `.svn` `.hg` `dist` `build` `target` `__pycache__` `.venv` `.next` `.svelte-kit` `.cache`
- 심볼릭 링크는 따라가지 않음
- 한 번에 최대 **20,000개** 항목까지만 색인 (얕은 곳부터 채움). 아주 큰 저장소에서는 깊은 파일이 안 보일 수 있음
- 색인은 5초 캐시. 방금 만든 파일은 몇 초 뒤에 나타남

### 작업 폴더 밖 경로

다음으로 시작하면 색인 검색 대신 **한 번에 한 폴더씩** 나열합니다.

| 입력 | 의미 |
|---|---|
| `#~`, `#~/work/` | 홈 디렉터리 |
| `#/etc/` | 절대 경로 |
| `#../` | 상위 폴더 |

숨김 항목(`.`으로 시작)은 입력이 `.`으로 시작할 때만 나옵니다. 서버가 워크스페이스로 제한(`PIPAYA_RESTRICT_WORKSPACE=1`)돼 있으면 그 밖의 경로는 거부됩니다. 경로를 알려 주는 것일 뿐이며 실제로 여는 것은 도구 권한과 승인 정책을 따릅니다.

## #image1 이미지 지목

이미지를 첨부하면 입력창에 `#image1`, `#image2`…가 **자동으로 삽입**됩니다. 여러 장일 때 어느 이미지를 말하는지 구분하는 용도입니다.

```text
#image1 이 변경 전, #image2 가 변경 후야. 차이를 설명해줘
```

- 번호는 첨부 순서(1부터)입니다. `#`을 입력하면 이미지가 파일보다 위에 나옵니다.
- 현재 첨부 장수 안의 토큰만 보라색으로 강조되고, 범위 밖 번호는 일반 글자입니다.
- 이미지를 지우면 해당 토큰이 글에서 지워지고 **뒤 번호가 한 칸씩 당겨집니다** (`#image3` → `#image2`).
- 토큰을 끝까지 직접 입력하면 메뉴가 다시 열리지 않아 {{Enter}}로 바로 전송됩니다.

## @ 세션 지목

다른 세션을 `@이름`으로 불러 일을 맡기거나 상황을 묻습니다. 동작 원리와 제한은 [[orchestration]]에 있습니다.

![`@`를 입력하면 ② 이 서버의 세션이 이름과 함께 나옵니다](/assets/img/ui/at.png)

```text
@미나 가 API를 만들고 있어. 끝나면 결과 읽고 프런트 연결해줘
```

- `@`를 입력하면 **자기 자신과 닫힌 세션을 뺀 모든 활성 세션**이 나옵니다. 분할 그룹에 속하지 않아도 됩니다.
- 이름(앞부분 일치) 또는 창 제목(포함 일치)으로 검색합니다.
- 항목에 창 제목, 폴더, 현재 상태(작업 중, 승인 대기 등)가 함께 보이고, 선택된 이름은 하늘색으로 강조됩니다.
- `@미나랑`, `@미나가`처럼 **조사가 붙어도** 인식합니다. 영문·숫자 이름은 더 긴 단어의 일부(`@mina2`의 `mina`)로는 인식하지 않습니다.
- 없는 이름은 강조되지 않고 일반 글자로 전달됩니다.

## / 명령·스킬·템플릿

메뉴에는 **명령 → 하위 에이전트 → 스킬 → 템플릿** 순서로 나오며 각각 태그가 붙습니다.

| 입력 | 의미 |
|---|---|
| `/new`, `/compact` 등 | 내장 명령 → [[slash-commands]] |
| `/subagent:이름` | 이 요청에 쓸 하위 에이전트 지정 → [[subagents]] |
| `/skill:이름` | 이 요청에 스킬 전문을 함께 전달 → [[skills]] |
| `/prompt:이름 인자` | 저장해 둔 프롬프트 템플릿 확장 → [[templates]] |

- 목록에 없는 `/xxx`를 보내면 **모델로 전송되지 않고** "알 수 없는 명령" 안내가 뜹니다. 입력은 그대로 남아 고칠 수 있습니다.
- 켜져 있는 스킬·하위 에이전트만 나옵니다. 서버 설정을 바꾸면 메뉴를 열 때 새로 읽습니다.
- 이미지를 첨부한 상태에서는 `/` 메뉴가 열리지 않습니다.
- 존재하는 `/skill:`, `/prompt:`, `/subagent:` 토큰은 강조 표시되고, 없는 이름은 일반 글자입니다.

## 첨부 방법

| 방법 | 설명 |
|---|---|
| 클립 버튼 | 여러 파일 선택 |
| 붙여넣기 | 클립보드의 이미지·파일(스크린샷 등) |
| 끌어놓기 | 창 어디든 놓으면 **선택된 창**에 첨부 ("파일을 놓아서 첨부" 표시) |

- 클립보드에 파일이 있으면 그 파일만 첨부되고 **함께 있던 텍스트는 붙여넣어지지 않습니다.** 글만 붙여넣을 때는 영향이 없습니다.
- 분할 화면에서는 포커스가 있는 창에만 첨부됩니다.
- 이름이 없는 붙여넣기 이미지는 `image`, 일반 파일은 `file`로 이름이 붙습니다.

## 이미지와 파일의 처리 차이

첨부물은 두 경로 중 하나로 처리됩니다.

| | **이미지로 전달** | **파일로 전달** |
|---|---|---|
| 조건 | 이미지 형식이고 선택된 모델이 **이미지를 볼 수 있음**(vision). SVG 제외 | 그 밖의 모든 것: 문서·코드·압축 파일, 이미지를 못 보는 모델에서의 이미지, SVG |
| 모델이 받는 것 | 이미지 자체 | 저장된 **경로, 형식, 크기 안내** |
| 저장 | 대화 기록에 포함 | 작업 폴더의 `.pipaya/uploads/` |
| 원본 | 축소·재인코딩됨 | **원본 그대로** |

### 이미지 변환

- 긴 변이 **1568px**를 넘으면 비율을 유지해 줄입니다.
- **600KB 미만 PNG**는 PNG를 유지하고(스크린샷이 선명하게 남음), 그 밖에는 **JPEG(품질 0.85)** 로 바꿉니다.
- 따라서 큰 PNG의 투명 배경은 사라지고 움직이는 GIF는 첫 장면만 남습니다. 원본이 필요하면 이미지를 못 보는 모델로 바꾸거나 압축해서 올려 파일로 전달하세요.

### 파일 저장 규칙

- 위치: 세션 작업 디렉터리의 `.pipaya/uploads/<무작위 6자>-<파일이름>`
- 파일 이름은 정리됩니다. 글자·숫자·`.`·`_`·`-` 외의 문자(공백 포함)는 `_`로, 맨 앞의 점은 `_`로 바뀌고, 끝 120자만 남습니다.
- 에이전트는 메시지에 붙은 안내(경로, MIME 형식, 바이트 수)로 위치를 알고 `read` 등으로 엽니다.
- 올린 파일을 서버가 자동으로 지우는 코드는 찾지 못했습니다. 필요하면 직접 정리하고, Git 저장소라면 `.pipaya/`를 `.gitignore`에 넣는 것을 권장합니다.

## 첨부 제한

클라이언트가 먼저 막고(알림 표시) 서버가 같은 값으로 다시 검사합니다.

| 항목 | 제한 | 초과 시 |
|---|---|---|
| 이미지 | **메시지당 8장** | "이미지는 최대 8장까지" 알림, 초과분 무시 |
| 파일 | **메시지당 8개** | "파일은 최대 8개까지" 알림, 이후 선택 중단 |
| 파일 1개 | **50MB** | 그 파일만 제외 |
| 파일 합계 | **100MB** | 그 파일만 제외 |
| 메시지 글자 | 1,000,000자 | 서버 거부 |
| 메시지 요청 크기 | 192MB (base64가 약 1.34배 커지는 것 감안) | 서버 거부 |
| 그 밖의 API 요청 | 2MB | 서버 거부 |

- 서버가 거부하면 `413 too_large`입니다.
- 이미지 8장과 파일 8개는 **별개 한도**이며 서로 세지 않습니다. 50MB·100MB 한도는 파일에만 적용됩니다.
- 파일은 브라우저 메모리에 base64로 올린 뒤 전송하므로 용량이 클수록 모바일에서 느리거나 메모리가 부족할 수 있습니다.
- 파일을 읽지 못하면 "○○를 읽지 못했습니다" 알림이 뜨고 그 파일만 제외됩니다.

## 첨부 카드와 미리보기

- 입력창 위에 카드로 표시됩니다. 이미지는 썸네일, 그 밖은 확장자 배지, 이름, 크기(B/KB/MB).
- 카드의 **×**로 제거합니다. 이미지는 `#imageN` 번호가 자동 정리됩니다.
- 보낸 메시지의 파일 카드를 누르면 미리보기가 열립니다.

| 종류 | 미리보기 |
|---|---|
| 이미지 (png jpg gif webp bmp avif svg) | 이미지 보기 (확대) |
| PDF | PDF 보기 |
| 오디오 (mp3 wav ogg m4a aac flac opus) | 재생 |
| 비디오 (mp4 m4v webm ogv mov) | 재생 |
| 마크다운 | 렌더링 |
| CSV / TSV | 표 (**앞 1,000행**) |
| 텍스트·코드 | 텍스트 (**앞 400,000자**, 넘으면 "앞부분만 보여 줍니다") |
| 그 밖 | 미리보기 없음 |

미리보기용 서버 조회(`GET /sessions/:id/files?path=`)는 파일을 **웹 페이지로 실행하지 못하게** 내려 보냅니다(`nosniff`, CSP `sandbox`). HTML 파일도 텍스트로만 보입니다. 50MB를 넘는 파일은 `413`입니다.

> [!WARNING]
> 이 조회는 작업 디렉터리 밖의 경로도 막지 않습니다. 이전에 있던 경로 제한은 커밋 `cb26464`에서 제거됐고, 현재 코드의 `safePath`는 경로를 그대로 돌려줍니다. 토큰이 있는 클라이언트는 서버 사용자가 읽을 수 있는 파일을 이 경로로 받을 수 있습니다. → [[security]]

에이전트 답변 속 **작업 폴더 기준 상대 경로 링크**(`src/a.ts` 등)를 누르면 같은 미리보기가 열립니다. 절대 경로(`/…`), `..`가 들어간 경로, `http:` 같은 주소는 해당하지 않습니다.

## 문제 해결

| 증상 | 원인과 조치 |
|---|---|
| 붙여넣은 스크린샷이 이미지가 아니라 파일로 들어감 | 선택된 모델이 이미지를 못 봄(vision 없음). 모델 변경 → [[models]] |
| 9번째 이미지가 안 붙음 | 메시지당 8장 한도. 나눠서 보내기 |
| `#` 메뉴에 방금 만든 파일이 없음 | 색인 캐시 5초. 잠시 뒤 다시 입력 |
| `#` 메뉴에 파일이 전혀 없음 | 제외 폴더 안이거나 20,000개 색인 한도를 넘은 깊은 경로. 폴더 경로를 단계별로 입력 |
| `@` 메뉴가 비어 있음 | 이름이 있는 다른 활성 세션이 없음. 새 대화를 하나 더 열기 |
| 큰 PNG의 배경이 검게 변함 | 600KB 이상 PNG는 JPEG로 변환됨. 이미지를 못 보는 모델을 쓰거나 압축해서 올리기 |
| `/xxx`가 전송되지 않음 | 존재하지 않는 명령은 모델에 보내지 않음. `/`로 목록 확인 |
| 업로드한 파일이 어디 있는지 모름 | 작업 폴더의 `.pipaya/uploads/` |
