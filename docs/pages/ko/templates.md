자주 쓰는 긴 요청을 파일로 저장해 두고 `/prompt:이름 [내용]`으로 부르는 기능입니다.

## 만들기

`<이름>.md` 파일 하나가 템플릿 하나입니다.

```markdown
---
description: 변경 사항을 코드 리뷰한다
---
현재 변경 사항을 정확성·보안·테스트 관점에서 리뷰해 주세요.
특히 확인할 내용: $ARGUMENTS
```

```text
/prompt:review 로그인 에러 처리
```

## 위치

| 범위 | 위치 |
|---|---|
| 프로젝트 | 작업 디렉터리에서 저장소 루트까지의 `.agents/templates/<이름>.md` |
| 전역 | `~/.agents/templates/<이름>.md` (서버 사용자의 홈) |

이름이 겹치면 더 가까운 폴더가 이기고(경고 표시), 프로젝트가 전역을 이깁니다. 전역 폴더가 상위 폴더라서 프로젝트 폴더로 잘못 잡히는 일은 막혀 있습니다.

## 파일 규칙

| 항목 | 값 |
|---|---|
| 이름 | 파일 이름(`.md` 제외) 또는 프론트매터의 `name`. 소문자·숫자·단일 하이픈, 최대 64자 |
| `description` | 메뉴에 보이는 설명. 비우면 **본문 첫 줄**(머리글 기호 제거, 120자까지) |
| 파일 크기 | 최대 128KB. 넘으면 건너뜀 |
| 개수 | 최대 200개 |
| 프론트매터 | 선택. YAML이 잘못되면 프론트매터가 없는 것으로 보고 파일 전체를 본문으로 씀 |

잘못된 파일은 경고와 함께 건너뜁니다(`GET /templates`의 `warnings`).

## 인자

| 상황 | 결과 |
|---|---|
| 본문에 `$ARGUMENTS`가 있음 | 모든 `$ARGUMENTS`를 호출 뒤에 쓴 내용으로 **치환** |
| `$ARGUMENTS`가 없음 | 호출 뒤에 쓴 내용을 본문 **끝에 덧붙임**(빈 줄 하나 뒤) |
| 인자 없이 호출 | 본문 그대로 |

번호 인자(`$1`)나 `$@` 같은 다른 자리표시자는 지원하지 않습니다.

## 호출 규칙

- 메시지 **맨 앞**에 `/prompt:이름`을 써야 합니다. 문장 중간에서는 템플릿으로 인식되지 않습니다.
- 이름은 소문자·숫자·하이픈입니다. 없는 이름이면 그냥 일반 글자로 보냅니다.
- 확장된 본문이 **사용자 메시지**가 되어 모델에게 전달됩니다. 대화 화면에는 짧은 호출문이 말풍선 아래 메모로 남습니다.
- 확장 결과는 최대 **60,000자**이며 넘으면 `[cut]`을 붙여 자릅니다.
- 세션의 제목이 비어 있으면 템플릿 이름이 제목이 됩니다.

## 확인과 갱신

- 입력창에서 `/`를 누르면 **템플릿** 태그로 보입니다. 상태줄의 `템플릿 N개`를 누르면 목록 창이 열립니다(검색, 새로고침, 프로젝트·전역 구분).
- 파일을 추가·수정하면 서버가 감지해(`skills_updated`) **새로고침 없이** 목록이 갱신됩니다.

## 템플릿 vs 스킬

| | 템플릿 | [[skills]] |
|---|---|---|
| 누가 호출 | 사용자만 (`/prompt:`) | 모델이 판단 또는 사용자 (`/skill:`) |
| 내용이 가는 곳 | 사용자 메시지로 직접 | 필요하면 모델이 읽음 |
| 용도 | 같은 **요청문** 반복 | 작업 **방법·지식** |

클라이언트 확장도 `commands`로 템플릿 방식의 `/명령`을 추가할 수 있습니다(`{{args}}` 자리표시자) → [[client-extensions]].
