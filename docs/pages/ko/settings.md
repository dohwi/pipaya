설정 화면의 항목과 각 값이 **어디에 저장되는지**를 정리합니다. pipaya의 설정은 기기에 남는 것과 서버에 저장되어 모든 기기가 공유하는 것으로 나뉩니다.

## 저장 위치 원칙

| 위치 | 성격 | 예 |
|---|---|---|
| **기기** (localStorage) | 이 기기만의 취향 | 테마, 단축키, 알림음, 사이드바, 서버 목록·토큰, 임시 초안, 즐겨찾기 모델 |
| **서버** (SQLite) | 서버에 연결한 모든 기기가 공유 | 모델 연결·기본값, 기본 폴더, 승인 정책, 압축, 하위 에이전트, 스킬 켜기/끄기, 그룹, 정리 정책 |
| **서버에 묶인 클라이언트 설정** | 서버별로 공유하되 클라이언트가 관리 | 즐겨찾기 모델(`favModels`), 설치한 확장(`extensions`), 알림 정책(`notificationPolicy`) |

서버에 묶인 클라이언트 설정은 `GET`/`PUT /client-settings/:key`로 동기화됩니다. 최신 값만 적용되며(오래된 쓰기는 `applied: false`), 키별 크기 상한이 있습니다.

| 키 | 상한 |
|---|---|
| `favModels` | 100,000자 |
| `extensions` | 13,500,000자 (확장 코드 포함) |
| `notificationPolicy` | 1,000자 |

## 설정 화면 구성

설정은 두 구역으로 나뉩니다. 위쪽 검색창에서 설정과 단축키를 함께 검색할 수 있습니다 (`설정·단축키 검색`).

![설정 화면. ① 왼쪽 목록에서 탭을 고르고 ② 오른쪽에서 값을 바꿉니다. 아래는 **도구 승인** 영역을 확대한 모습](/assets/img/ui/settings.png)

### 앱 설정 (이 기기)

| 탭 | 내용 |
|---|---|
| 일반 | 언어 · 테마 · 도구 승인 · 질문 · 알림음 · 알림 · 업데이트 |
| 단축키 | 키 지정과 초기화 |
| 확장 | 이 기기에 설치한 클라이언트 확장 → [[client-extensions]] |
| 백업 | 설정 내보내기·가져오기 |

### 서버 설정 (선택한 서버)

| 탭 | 내용 |
|---|---|
| 정보 | 서버 이름·주소·토큰 편집, 연결 확인, 서버 버전 |
| 기본 폴더 | 이 서버에서 새 대화가 시작되는 위치 |
| 모델 연결 | 연결 추가·수정·삭제, 기본값, 압축 모델 → [[models]] |
| 에이전트 | 하위 에이전트 → [[subagents]] |
| 대화 | 대화 목록, 일괄 삭제, 자동 삭제 → [[sessions]] |
| 기기 | 연결된 기기, QR 연결 → [[notifications]] |

서버는 여러 개 등록할 수 있고 {{Mod+Comma}}로 설정을 열고, *다음 서버로 전환* 단축키로 서버를 바꿉니다.

## 일반 탭

| 항목 | 기본 | 저장 | 설명 |
|---|---|---|---|
| 언어 | 시스템 | 기기 | 시스템을 따르거나 한국어·영어(및 설치한 언어팩)를 직접 선택 |
| 테마 | 시스템 | 기기 | 시스템 / 라이트 / 다크 ({{Mod+Comma}} 설정, 라이트·다크 전환 단축키는 기본 지정 없음) |
| 도구 승인 | 프로젝트 밖만 확인 | **서버** | `ask`("프로젝트 폴더 밖의 파일을 고치거나 밖의 경로를 건드리는 명령을 실행할 때만 확인") 또는 `auto`("묻지 않고 모두 실행"). 앞으로 시작할 **새 대화**에 적용 |
| 질문 허용 | 켜짐 | **서버** | 끄면 에이전트가 `ask_user` 없이 가정하고 진행. 모든 대화에 적용 |
| 알림음 | 켜짐 | 기기 | 작업 완료·확인 필요·실패 때 소리 재생 |
| 알림음 크기 | 100 | 기기 | 0~200. 보고 있는 대화가 끝날 때는 울리지 않고 승인 요청은 보고 있어도 울림 |
| 시스템 알림 | — | 기기+서버 | → [[notifications]] |
| 시작할 때 새 버전 확인 | — | 기기 | 앱 시작 때 업데이트 확인 → [[updates]] |

> [!NOTE]
> 설정의 **도구 승인**은 서버의 기본 정책이며 이미 만들어진 대화는 바꾸지 않습니다. 세션마다 바꾸려면 *승인 방식 변경* 단축키나 세션 설정을 쓰세요.

## 기본 폴더

새 대화가 시작되는 작업 디렉터리입니다. 폴더 선택기에서 서버의 폴더를 탐색하고 새 폴더도 만들 수 있습니다.

- 변경하면 바로 저장되고 이후 새 대화부터 적용됩니다.
- 서버의 저장된 값이 없으면 서버를 처음 켤 때의 설정(`PIPAYA_WORKSPACE`)을 씁니다. `null`로 지우면 그 값으로 복원됩니다.
- 입력은 **존재하는 절대 경로**여야 합니다.
- 서버 `PIPAYA_RESTRICT_WORKSPACE=1`이면 워크스페이스 안의 경로만 허용됩니다.
- 선택기는 폴더만 보여 주고(숨김 폴더는 옵션), 한 번에 최대 500개까지 나열합니다.

`/cd`로 현재 대화의 작업 디렉터리를 바꿀 수도 있습니다.

## 단축키 탭

![단축키 탭](/assets/img/ui/settings-keys.png)

모든 단축키를 바꾸거나 없앨 수 있습니다. 기본값과 규칙은 [[shortcuts]]에 있습니다.

- 키 지정은 **녹음 방식**입니다. 누른 키가 화면에 쌓이고 체크 버튼을 눌러야 저장됩니다. {{Backspace}}는 마지막 키를 취소하고, 더 취소할 키가 없으면 단축키를 지웁니다. {{Escape}}는 녹음을 취소합니다.
- 수정 키({{Mod}} {{Alt}} {{Shift}}) 뒤에 **일반 키를 최대 3개**까지 이어서 지정할 수 있습니다(`Mod+B+V`처럼 누른 순서대로). 초과하면 알림이 뜹니다.
- 이미 다른 동작이 쓰는 조합이면 **그 동작에서 가져옵니다**("○○에서 이 단축키를 가져왔습니다").
- 기본값에서 바꾼 것만 저장됩니다(`pipaya.keys`).
- 검색창에서 이름·설명·키로 거를 수 있습니다.

## 모델 연결 탭

![모델 연결 탭](/assets/img/ui/settings-models.png)

연결 추가·수정·삭제, 기본값, 컨텍스트 압축 모델을 한 곳에서 다룹니다. 자세한 내용은 [[models]]에, 압축은 [[context]]에 있습니다.

| 항목 | 설명 |
|---|---|
| 연결 추가 | 내장 프로바이더 / 로컬 프리셋 / 직접 입력 |
| 기본값 | 새 대화의 기본 모델 |
| 컨텍스트 압축 모델 | 요약을 쓰는 모델. 비우면 "세션 모델 그대로 사용" |
| 자동 압축 | 컨텍스트가 가득 차면 자동으로 압축 |

압축 모델의 연결에 키가 없으면 "이 모델의 연결에 키가 없어 압축이 실패합니다" 경고가 나옵니다.

| 항목 | 설명 |

## 백업 탭

![백업 탭](/assets/img/ui/settings-backup.png)

설정을 JSON 파일 하나로 내보내고 가져옵니다. 다른 기기나 새로 설치한 앱으로 옮길 때 씁니다.

### 내보내기

| 항목 | 내용 |
|---|---|
| 서버 연결 | **이름과 주소만.** 토큰은 들어가지 않음 |
| 이 기기의 확장 | 이 기기에만 설치한 확장의 패키지와 비민감 설정. 서버에 있는 확장은 제외 |
| 앱 설정 | 테마, 알림음 사용 여부와 크기 |
| 단축키 | 기본값에서 바꾼 것만 |

비밀번호나 토큰처럼 보이는 값은 빠집니다. 다만 확장 코드나 기본값에 직접 적어 둔 비밀은 걸러내지 못하니 파일을 남에게 보내기 전에 확인하세요.

### 가져오기

- 파일은 **최대 4MiB**, JSON이어야 합니다. 끌어다 놓거나 눌러서 고릅니다.
- 가져오기 전에 **바뀌는 내용 미리보기**(서버 추가, 확장 설치·교체·변경, 없음)를 보여 줍니다. 지금 설정과 같으면 "바꿀 것이 없습니다".
- 이미 있는 서버는 **주소로 찾아 이름만 맞추고** 토큰은 그대로 둡니다.
- 확장은 이 기기의 확장으로, **모두 꺼진 상태**로 들어옵니다. 권한을 확인한 뒤 직접 켜세요.
- 적용 직전의 상태를 이 기기에 백업해 두므로 **되돌리기**로 취소할 수 있습니다.

## 기기에 저장되는 키

| localStorage 키 | 내용 |
|---|---|
| `pipaya.servers`, `pipaya.server`, `pipaya.conn` | 서버 목록, 선택한 서버, 연결 정보 |
| `pipaya.active.<서버>` | 서버별 열려 있던 대화 |
| `pipaya.theme` | 테마 |
| `pipaya.sound`, `pipaya.volume2` | 알림음 사용 여부, 크기 |
| `pipaya.keys` | 바꾼 단축키 |
| `pipaya.draft` | 작성 중인 글 |
| `pipaya.sidebar`, `pipaya.sidebar.w` | 사이드바 접힘, 너비 |
| `pipaya.workdir.<서버>` | 서버별 마지막 작업 폴더 |
| `pipaya.fav.models.<서버>` | 즐겨찾기 모델 |
| `pipaya.folded`, `pipaya.dirOrder`, `pipaya.grouporder`, `pipaya.fullgroups` | 접힘·정렬·전체 모드 |

> [!WARNING]
> 서버 토큰은 이 기기의 localStorage에 평문으로 남습니다. 공용 컴퓨터에서는 쓰지 말고, 쓰던 기기는 해지하세요 → [[notifications]].
