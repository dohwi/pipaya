pipaya는 **내 서버에서 돌리는 AI 에이전트 채팅 도구**입니다. 서버가 모델 호출과 도구 실행을 맡고, 앱(클라이언트)은 어느 기기에서든 같은 서버에 접속해 대화합니다. 세션, 설정, API 키는 내 서버의 SQLite에만 저장됩니다.

## 구성

| 구분 | 기술 | 역할 |
|---|---|---|
| 서버 | Bun, Fastify, SQLite | 에이전트 실행, 세션·설정 저장. **화면 없는 API 전용** |
| 클라이언트 | Svelte 5, Vite, Tauri 2 | 웹, Windows, macOS, Android, iOS 앱 |
| 통신 | REST, SSE, WebSocket | 명령은 REST, 진행 상황은 SSE/WebSocket으로 실시간 전달 |
| 에이전트 루프 | `pi-agent-core` | 모델 호출과 도구 실행을 번갈아 수행 |
| 격리 | Docker(선택) | 에이전트의 파일·명령 작업을 컨테이너 안으로 제한 |

서버와 클라이언트는 서로 독립적으로 실행됩니다. 서버 하나에 여러 기기가 동시에 접속할 수 있고, 모든 기기가 같은 세션·설정을 봅니다.

```text
[ 클라이언트 ]  ──REST / SSE / WebSocket──▶  [ pipaya 서버 ]  ──▶  [ 모델 API ]
 웹 · 데스크톱 · 모바일                       세션 · 도구 · SQLite     OpenAI · Anthropic · 로컬
```

## 할 수 있는 일

에이전트는 목표와 작업 폴더를 받으면 파일을 읽고, 고치고, 명령을 실행하며 여러 단계 작업을 처리합니다. 소프트웨어 개발뿐 아니라 문서 정리, 자료 조사, 데이터 파일 처리에도 쓸 수 있습니다.

| 기능 | 설명 | 문서 |
|---|---|---|
| 10가지 내장 도구 | `read` `write` `edit` `ls` `grep` `bash` `ask_user` `delegate` `peer_send` `peer_read` | [[tools]] |
| 승인 정책 | `ask` `auto` `readonly`. 변경 작업을 사용자가 통제 | [[tools]] |
| 모델 자유도 | 내장 프로바이더, 로컬 서버, 직접 만든 엔드포인트. 용도별 모델 분리 | [[models]] |
| 대화 도구 | 끼워 넣기·대기열, 분기, 재시도, 압축, 닫기·재개 | [[sessions]] |
| 입력창 | `/` 명령, `#` 파일, `@` 세션, 이미지 붙여넣기, 파일 업로드 | [[composer]] |
| 세션 협업 | `@이름`으로 다른 세션에 일을 맡기고 결과를 읽음 | [[orchestration]] |
| 분할 화면 | 최대 8개 대화를 한 화면에, 서버 셸(터미널) 통합 | [[panes]] |
| 다중 기기 | QR 1회용 코드로 연결, 기기별 토큰, 알림·모바일 푸시 | [[notifications]] |
| 확장 | AGENTS.md, 스킬, 템플릿, 하위 에이전트, 서버·클라이언트 확장 | [[agents-md]] |

## 특징

### 데이터는 내 서버에만
대화, 키, 토큰이 모두 내 서버에 있습니다. 클라우드 계정이 필요 없고 모델 연결도 서버 한 곳에서만 설정합니다. 새 서버에는 모델이 하나도 연결되어 있지 않습니다.

### 변경 작업을 사용자가 통제
`write`, `edit`, `bash`는 승인 정책을 따릅니다. 기본 정책 `ask`는 프로젝트 폴더 밖에 영향을 주는 작업만 확인합니다. 승인 요청은 10분 안에 답이 없으면 자동 거부됩니다.

> [!WARNING]
> 읽기 도구(`read`, `ls`, `grep`)는 승인 대상이 아니며 **작업 폴더 밖의 파일도 읽을 수 있습니다.** 서버 사용자 권한으로 접근 가능한 파일은 모두 읽힌다고 보고 운영하세요. 자세한 내용은 [[security]]를 참고하세요.

### 여러 기기에서 이어서
접속이 끊겨도 저장된 이벤트(7일)로 이어서 복구합니다. 작업이 끝나거나 승인이 필요하면 알림이 가고, 이미 보고 있는 기기에는 중복해서 보내지 않습니다.

### 직접 확장
서버 확장은 도구와 `/명령`을 추가하고 에이전트 동작에 훅을 걸 수 있습니다. 클라이언트 확장은 샌드박스 안에서 화면 패널, 테마, 언어팩을 추가합니다.
