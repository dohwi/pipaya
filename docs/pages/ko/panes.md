여러 대화와 서버 터미널을 한 화면에 나눠 놓는 방법입니다.

## 그룹

**그룹**은 2~8개의 대화(또는 터미널)를 한 화면에 배치한 레이아웃입니다.

| 항목 | 값 |
|---|---|
| 구성원 | **2~8개**. 8개를 넘기면 거부(`a group holds at most 8 sessions`), 2개 미만이면 거부 |
| 이름 | 1~100자. 비우면 서버가 `Group N`을 붙임 (앱은 보통 현지화된 이름을 보냄) |
| 분할 비율 | 0.1 ~ 0.9 (그 밖의 값은 범위로 맞춤) |
| 중첩 깊이 | 최대 8 |
| 저장 | **서버**. 모든 기기에서 같은 그룹이 보임 |

그룹이 2개 미만이 되면(대화를 닫거나 지우거나 그룹에서 빼면) 서버가 그룹을 지우고 `group_deleted` 이벤트를 보냅니다. 대화 자체는 그대로 남습니다.

## 레이아웃 구조

레이아웃은 이진 분할 트리입니다.

```json
{
  "type": "split", "dir": "row", "ratio": 0.5,
  "a": { "type": "pane", "sessionId": "…" },
  "b": { "type": "pane", "sessionId": "…" }
}
```

`dir: "row"`는 `a`를 왼쪽·`b`를 오른쪽, `dir: "col"`은 `a`를 위·`b`를 아래에 둡니다. `POST /groups`, `PATCH /groups/:id`(이름·레이아웃), `DELETE /groups/:id`로 다룹니다.

## 만들고 바꾸기

| 방법 | 동작 |
|---|---|
| 사이드바에서 대화를 다른 대화 위로 끌어다 놓기 | 두 대화를 묶음 |
| 대화를 다른 **창**(칸) 위로 끌기 | 놓는 위치에 따라 왼쪽·오른쪽·위·아래로 분할 |
| 행 메뉴 → **다른 대화와 묶기** | 끌기가 안 되는 터치 기기용. 묶을 대화를 목록에서 고름 |
| 단축키 | 오른쪽 분할 {{Mod+\}}, 아래 분할 {{Mod+Shift+\}}. 왼쪽·위 분할은 기본 지정이 없음 |
| 그룹 해제 | 사이드바 그룹 행 메뉴, 또는 *현재 창을 그룹에서 빼기* 단축키 |

창 위로 끌 때 놓을 영역(왼쪽·오른쪽·위·아래)이 하이라이트됩니다. 자기 자신 위에는 놓을 수 없습니다. 그룹이 이미 8창이면 더 넣을 수 없고 "그룹에는 대화를 최대 8개까지 넣을 수 있습니다" 알림이 뜹니다.

## 분할선 조절

분할선을 끌어 크기를 바꿉니다.

| 조작 | 동작 |
|---|---|
| 끌기 | 이 분할선만 이동 |
| {{Shift}} + 끌기 | 같은 선상으로 이어진 분할선을 함께 이동 |
| {{Ctrl}}(Mac은 {{Cmd}}) + 끌기 | 다른 분할선의 가이드에 맞춤 |
| 더블 클릭 | 반반(50%)으로 되돌림. {{Shift}}를 누르면 이어진 선 전체 |

## 창과 포커스

![두 대화를 묶은 그룹. ① 사이드바의 그룹 행 ② 포커스가 있는 창(주황 테두리) ③ 다른 창(파랑 테두리)](/assets/img/ui/group.png)

- **창 제목 줄**에 대화 이름(`@미나`)과 제목이 보이고, 긴 제목은 선택된 창에서 흘러가며 보입니다. 제목 줄을 끌면 다른 칸으로 옮길 수 있습니다.
- 선택된(포커스가 있는) 창에서만 입력, 파일 끌어놓기, 단축키가 동작합니다.
- 창 이동: *왼쪽·오른쪽·위쪽·아래쪽 창으로 포커스*, *다음 창으로 포커스* 단축키 (기본 지정 없음 → [[shortcuts]]).
- 창 제목 줄의 버튼: **크게 보기**, **그룹에서 빼기**, 터미널이면 **터미널 닫기**.

### 크게 보기와 전체 모드

| 동작 | 설명 |
|---|---|
| 창 제목 줄 더블 클릭 / **크게 보기** 버튼 | 선택한 창을 **임시로** 크게 보기. {{Escape}} 또는 **작게 보기**로 되돌림 |
| 그룹의 **전체 모드** | 그룹 전체를 크게 보기 모드로 두고, 다른 창을 한 줄 스트립으로 전환. 이 상태는 기기에 저장됨 |

## 사이드바에서의 표시

사이드바는 폴더별로 대화를 묶어 보여 주고, 그룹은 구분선과 함께 별도 묶음으로 나옵니다. 사이드바를 접으면 세로 레일에 활성 대화와 그룹이 아이콘으로 남습니다.

| 기능 | 설명 |
|---|---|
| 검색 | 대화 제목·이름으로 찾기 |
| 접기·펼치기 | 폴더 묶음을 접을 수 있음 (접힘 상태는 기기에 저장, 검색 중에는 항상 펼침) |
| 순서 바꾸기 | 같은 폴더의 낱개 대화를 끌어 순서를 바꾸고, 폴더·그룹 머리글을 끌어 순서를 바꿈 (기기에 저장) |
| 더블 클릭 | 현재 서버의 대화 이름 바꾸기 |
| 행 메뉴 | 다른 대화와 묶기 / 이름 바꾸기 / 닫기 (`/resume`으로 다시 열기) / 터미널이면 터미널 닫기 |
| 분기 표시 | 분기된 대화에는 분기 아이콘 |
| 상태 | 대화별 실행 중·승인 대기·끝남 표시, 서버별 연결 상태(연결 안 됨, 토큰 거부됨, 앱 업데이트 필요) |
| `새 대화` / `새 터미널` | 각 폴더 머리글에서 그 폴더 기준으로 시작 |

폴더 머리글의 메뉴에서 그 폴더의 **새 대화** 또는 **새 터미널**을 바로 만들 수 있습니다. 사이드바 접기는 {{Mod+B}}입니다.

## 터미널

서버 머신의 셸을 앱의 창으로 엽니다. 대화 옆에 나란히 놓을 수 있고 그룹에 넣을 수도 있습니다.

| 항목 | 내용 |
|---|---|
| 열기 | 사이드바 폴더 머리글의 **새 터미널**, {{Mod+Shift+`}} (현재 작업 폴더에서), {{Mod+Alt+`}} (선택한 창 아래에 열고 그룹으로 묶음) |
| 셸 | Linux·macOS는 `$SHELL`(없으면 bash → zsh → fish → sh 순으로 찾음), Windows는 PowerShell 우선 |
| 구현 | Linux·macOS는 **진짜 의사 터미널(PTY)**. Windows는 PTY가 없어 **파이프**로 동작하고 클라이언트가 입력을 대신 에코함 |
| 시작 폴더 | 지정한 `cwd`(없으면 기본 작업 디렉터리 기준) |
| 개수 | 서버당 최대 **16개** |
| 스크롤백 | 터미널마다 마지막 출력 **512KB**를 보관. 다시 연결하면 그 화면이 복원됨 |
| 다중 접속 | 여러 클라이언트가 한 터미널에 동시에 붙을 수 있음 |
| 크기 | 열 2~1000, 행 1~500. 창 크기를 바꾸면 따라 조절됨 |
| 종료 | 닫으면 셸에 `SIGHUP`, 잠시 뒤 안 끝나면 `SIGKILL`. 셸이 종료되면 "셸이 종료되었습니다 (코드 N)" 표시 |
| 수명 | **메모리에만 있음**. 서버를 재시작하면 모두 사라짐 |
| 환경 | 서버 환경에서 `PIPAYA_*`를 뺀 것 + `TERM=xterm-256color`, `COLORTERM=truecolor`, `TERM_PROGRAM=pipaya` |

> [!WARNING]
> 터미널은 **승인 정책과 무관한 완전한 셸**입니다. 토큰이 있는 기기는 서버 사용자 권한으로 아무 명령이나 실행할 수 있습니다. 쓰지 않으려면 서버를 `PIPAYA_TERMINAL=0`으로 띄우세요. 서버가 `PIPAYA_RESTRICT_WORKSPACE=1`이면 터미널의 시작 폴더도 워크스페이스 안으로 제한됩니다.

통신은 `GET /terminals/:id/ws` 웹소켓으로, 서버가 출력을 바이너리 프레임으로 보내고 클라이언트가 `{type:"input", data}`, `{type:"resize", cols, rows}`를 보냅니다. 느린 클라이언트(4MB 이상 밀림)는 연결이 닫히고, 다시 붙으면 스크롤백을 받습니다. REST는 `GET /terminals/info`(지원 여부·셸 목록), `GET`/`POST /terminals`, `PATCH`/`DELETE /terminals/:id`입니다.

각 대화 입력창 아래에 보이는 정보입니다 → [[context]].

| 출력 속도 | 마지막 응답의 tps |
| 누적 비용 | 이 대화의 비용과 모델 호출 수 |

## 명령 팔레트

앱의 선택 창(팔레트)은 `/resume`, `/tree`, `/cd` 같은 명령이 목록을 보여 줄 때 열립니다. 검색창에 입력하면 제목과 부제로 거르고, {{↑}} {{↓}}로 이동, {{Enter}}로 선택, {{Escape}}로 닫습니다. 일치하는 항목이 없으면 "일치하는 항목이 없습니다"가 나옵니다. `/delete`는 "정말 삭제할까요? 복구할 수 없습니다" 확인을 이 창으로 받습니다.
