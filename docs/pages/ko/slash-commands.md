입력창에서 `/`를 입력하면 명령 메뉴가 열립니다. 명령은 **서버가 아니라 앱**이 실행하는 것이 대부분이라, 로컬에서 처리되는 명령은 오프라인에서도 동작합니다.

## 내장 명령

| 명령 | 인자 | 설명 | 열린 대화 필요 |
|---|---|---|---|
| `/new` | | 새 대화 시작 | 아니오 |
| `/resume` | | 닫은 대화 다시 열기 (닫은 대화 포함 목록에서 선택) | 아니오 |
| `/rename` | `<제목>` | 대화 이름 바꾸기. 제목이 없으면 안내만 표시 | 예 |
| `/close` | | 대화 닫기. **기록은 유지** | 예 |
| `/cd` | `[경로]` | 작업 디렉터리 변경. 경로 없이 쓰면 폴더 선택기(또는 서버 기본 / 사용 중인 폴더 목록) | 아니오 |
| `/compact` | `[지침]` | 컨텍스트 압축. 요약 호출 비용 발생. 지침은 최대 2,000자 | 예 |
| `/retry` | | 마지막 응답 재시도 | 예 |
| `/stop` | | 진행 중인 작업 중지 | 예 |
| `/cancel` | | 대기열·끼워 넣기 메시지 취소 창 열기 | 예 |
| `/fork` | `[last]` | 대화 분기. `last`는 마지막 응답 직전에서 분기 | 예 |
| `/tree` | | 대화 분기 트리 (열린 대화가 있으면 그 가족만, 없으면 폴더별 전체) | 아니오 |
| `/copy` | | 마지막 답변 텍스트를 클립보드에 복사 | 예 |
| `/delete` | | 대화 **영구 삭제**. 확인 창이 한 번 더 뜸 | 예 |

- 모든 내장 명령은 `/이름` 형식의 **영어 이름 하나**만 있습니다. 한국어·중복 별칭은 없습니다.
- 사이드바 토글, 모델, 추론, 도움말은 명령이 아니라 UI와 단축키로 합니다.
- 열린 대화가 필요한 명령을 새 대화 화면에서 쓰면 동작하지 않습니다.

## 명령의 동작 규칙

- 명령은 입력창 **맨 앞**에서 `/이름 [인자]` 형태로 씁니다.
- 실행 중이어도 `/stop`, `/cancel` 같은 명령은 바로 실행됩니다(작업 중 {{Enter}}는 끼워 넣기이지만 명령은 가로채서 실행).
- 목록에 **없는** 명령(`/xxx`)을 보내면 모델에 전달되지 않고 "알 수 없는 명령입니다. /를 입력해 목록을 확인하세요" 알림만 뜹니다. 입력은 남아 있어 고칠 수 있습니다.
- 인자가 필요한 명령(`/rename`)은 {{Tab}}으로 입력만 완성하고, 인자가 선택인 명령(`/compact`, `/cd`, `/fork`)은 선택하면 바로 실행합니다.
- 인자가 고정된 선택지인 명령은 인자 메뉴가 이어서 열립니다.

## 접두어 호출

`/` 메뉴에는 내장 명령 뒤에 아래 항목이 **태그**와 함께 나옵니다.

| 형식 | 의미 | 문서 |
|---|---|---|
| `/subagent:이름` | 이번 요청에 쓸 하위 에이전트 지정 | [[subagents]] |
| `/skill:이름` | 이번 요청에 스킬 전문을 함께 전달 | [[skills]] |
| `/prompt:이름 [인자]` | 저장해 둔 프롬프트 템플릿 확장. 메시지 **맨 앞**에서만 | [[templates]] |
| `/확장명령` | 서버 확장·클라이언트 확장이 등록한 명령 | [[server-extensions]], [[client-extensions]] |

서버 확장이 등록한 명령은 앱의 `/` 메뉴에 함께 나옵니다. 고르면 `/이름 인자`가 **메시지로 서버에 전송**되고, 서버가 모델 대신 확장 명령을 실행합니다. 확장이 문자열을 돌려주면 그것이 사용자 메시지로 모델에 전달됩니다. 이름은 소문자·숫자·하이픈이어야 메뉴에 나오며, **앱 내장 명령이나 클라이언트 확장 명령과 이름이 겹치면 서버 확장 쪽이 메뉴에서 빠집니다.**

## 기호 입력

`/` 외에 입력창에서 쓰는 기호입니다 → [[composer]].

| 기호 | 의미 |
|---|---|
| `#경로` | 작업 폴더의 파일·폴더 |
| `#image1` | 첨부한 이미지 |
| `@이름` | 다른 세션 → [[orchestration]] |

## 단축키로 하는 같은 동작

| 명령 | 단축키 동작 |
|---|---|
| `/new` | 새 대화 ({{Alt+N}}) |
| `/close` | 현재 대화 닫기 ({{Alt+W}}) |
| `/resume` | 대화 열기 ({{Alt+O}}) |
| `/stop` | 작업 중지 ({{Escape}}) |
| `/cancel` | 대기열 취소 ({{Alt+Q}}) |
| `/fork`, `/retry`, `/compact`, `/copy` | 같은 이름의 단축키 (기본 지정 없음) |
| `/cd` | 작업 폴더 변경 (기본 지정 없음) |

전체 목록은 [[shortcuts]]에 있습니다.
