서버와 클라이언트를 설치했다면 ([[installation]]) 아래 5단계로 첫 대화까지 갑니다.

::: steps
### 서버 연결

앱을 처음 열면 연결 화면이 나옵니다.

![처음 열면 나오는 연결 화면. ①의 **서버 주소로 연결**을 누릅니다](/assets/img/ui/connect.png)

| 입력 | 값 |
|---|---|
| 이름 | 표시용 이름 (예: 집 서버) |
| 서버 주소 | `http://<서버 주소>:8787` |
| 액세스 토큰 | 서버의 `~/.pipaya/token` 내용 |

![서버 추가 폼. ① 이름 ② 서버 주소 ③ 토큰을 넣고 ④ **추가**를 누릅니다](/assets/img/ui/connect-form.png)

저장하기 전에 연결을 확인하며, 토큰은 이 기기에만 저장됩니다. 암호화되지 않은 `http` 주소로 인터넷을 거치면 토큰이 노출될 수 있으니 Tailscale 주소나 `https`를 쓰세요.

### 모델 연결

새 서버에는 모델이 하나도 없어서 연결해야 채팅할 수 있습니다. 화면의 **모델 연결** 버튼, 또는 **설정 → 모델 연결 → 연결 추가**를 엽니다.

| 방식 | 설명 |
|---|---|
| 내장 프로바이더 | 목록에서 고르고 API 키를 입력하거나 계정으로 로그인(OAuth) |
| 로컬 모델 | Ollama, LM Studio, llama.cpp, vLLM 프리셋 선택 |
| 직접 입력 | 연결 이름, Base URL, 모델 ID, API 형식 입력 |

자세한 내용은 [[models]]를 보세요.

### 새 대화와 작업 폴더

{{Alt+N}} 또는 `/new`로 새 대화를 시작합니다. 에이전트가 일할 **작업 디렉터리**는 입력창 위에 표시되며, 눌러서 바꾸거나 `/cd`로 바꿉니다. 입력창 아래에서 모델과 추론 강도도 확인하세요.

![첫 화면. ① 사이드바(서버·폴더·대화 목록) ② 작업 디렉터리 ③ 입력창 ④ 파일 첨부 ⑤ 모델·추론 강도 ⑥ 보내기 ⑦ 설정](/assets/img/ui/home.png)

### 메시지 보내기

```text
이 폴더의 구조를 설명해줘
```

![도구를 쓴 대화. ① 도구 호출 줄(`ls`)이 접힌 채 결과와 함께 남고 ② 답변이 이어지며 ③ 모델·추론 강도·토큰·응답 시간이 붙습니다](/assets/img/ui/chat.png)

에이전트가 파일을 읽고 답합니다. 파일을 고치거나 명령을 실행하려 하면 **승인 카드**가 나타납니다. 기본 정책 `ask`에서는 작업 폴더 밖에 영향을 주는 작업만 확인을 요청합니다. 자세한 규칙은 [[tools]]에 있습니다.

### 자주 쓰는 동작

| 하고 싶은 일 | 방법 |
|---|---|
| 작업 중단 | {{Escape}} 또는 `/stop` |
| 응답 다시 받기 | `/retry` |
| 긴 대화 정리 | `/compact` |
| 다른 방향 시도 | `/fork` |
| 닫은 대화 열기 | `/resume` |
| 파일 지목 | `#` 입력 후 선택 |
| 다른 세션 지목 | `@` 입력 후 선택 |
:::

## 폰·다른 PC 연결 (QR)

토큰을 직접 옮기지 않고 연결할 수 있습니다.

1. 이미 연결된 PC 앱에서 **설정 → 기기 → 폰 추가**를 엽니다.
2. 폰이 접근할 수 있는 주소인지 확인합니다. `localhost` 주소는 폰에서 폰 자신을 가리키므로 Tailscale 주소나 LAN 주소로 바꿉니다.
3. **QR 만들기**를 누르고 새 기기에서 앱을 열어 QR을 스캔합니다.

코드는 **2분 안에 한 번만** 쓸 수 있고, QR에는 관리자 토큰이 들어 있지 않습니다. 새 기기는 그 기기 전용 토큰을 받으며, 나중에 기기별로 해지할 수 있습니다. 자세한 내용은 [[notifications]]를 보세요.
